Help with LinguaFast.

Using the translator, understanding your data, and getting help with releases.

Contact and support

For non-sensitive problems, suggestions or feature requests, use the project's public GitHub issue tracker. Include the LinguaFast version, Android version, what happened and what you expected. Do not post API keys, signing details, email addresses, personal conversations or private logs.

A verified, private developer support email is still being prepared for the Google Play listing. A public issue tracker is not a private contact channel, and it does not replace the Play Console requirement for a valid support contact.

Quick Setup and getting started

First use: Choose the FROM and TO languages for text translation. Setting FROM to Auto-detect shows an identified or likely source language when supported; selecting a language yourself is always respected. For Conversation, choose Speaker A and Speaker B languages and optionally Guest C. Tap each coloured microphone; Android will request microphone permission. If detection mishears a short phrase, choose a fixed spoken language.

Instant (free) translates without an AI API key. AI is optional: use Settings to select a provider, paste a key, tap Test key, and Save to keep it encrypted on Android. Keys and translation text go to the selected provider only when you use an AI feature; provider charges and limits vary.

Guided first-run setup: The published v42 Android update includes a simple Quick Setup covering these three choices in one sheet, with Save languages, Use free Instant and Set up AI key. It opens on genuinely fresh Android installs and remains accessible from Help and the page footer. It does not reset the language choices, history or saved provider keys of existing users. This is included in the official v42 signed APK. Installation still requires Android approval.

Language of the app's own interface

Since v40, LinguaFast follows the Android device's primary language for its main translated interface labels when one of these 12 languages is supported: English, Thai, Vietnamese, Spanish, French, German, Chinese, Japanese, Korean, Portuguese, Indonesian and Malay. The main navigation, selected language dropdown names (where the device supports them), primary actions and placeholders can change when you reopen or return to the app. Other advanced settings, some help sheets and live status messages still use English. An unsupported phone language falls back to English.

Important: changing Android's interface language never changes your selected FROM, TO, Speaker A, Speaker B or Guest C languages, message content, saved history or provider keys. System interface translation is separate from translating what you type or say.

AI keys and different providers

Open Settings → AI Mode to select, test and save a provider. Since v25, the Settings screen keeps the provider list visible and stays open after Save so you can add another provider. On the main screen, choose AI, then expand the compact AI provider selector to switch saved channels. Saved profiles keep separate keys, models and API URLs when Remember AI keys is selected.

Current presets: Google Gemini, Groq, OpenRouter, OpenAI, DeepSeek and a custom compatible endpoint. Adding new provider presets does not require a fixed maximum number of saved-key slots.

If AI Polish declines a message, the provider may have returned no text, refused it, hit an output limit or encountered a configuration/quota problem. The app should preserve the original draft and report a more specific reason where the provider supplies it. Provider policies cannot be bypassed by saving a different key.

One-tap Polish and Undo (v33 onward)

In Translate, type or dictate a draft and tap ✨ Polish. The corrected text replaces that draft after the AI request succeeds. Tap ↶ Undo to restore the exact previous text without sending another AI request. A further manual edit invalidates the earlier Undo to protect your newer wording. Polish is optional; it is not a request on each keystroke. In Conversation, expand Type, dictate or Polish a message for the same one-tap correction and Undo on typed/dictated drafts; live speaker messages are not silently polished. A long draft can require multiple provider requests, and the provider may bill for them.

Using the current v42 layout

Translate: choose the source/target languages at the top, enter or dictate the original message and use the Translate button. The matching outlined translation result appears directly underneath. Copy, playback, stop, save and WhatsApp controls remain available. Open the compact AI channel selector when using AI mode to switch saved providers. The model name does not dominate the main screen. The Phrases · History · Saved area is expanded by default; choose History or Saved, then tap a bilingual record to open it, or use its Copy, Speak and Delete controls. Each record keeps its full height instead of being compressed. Translation actions use small, borderless icons in even-width rows so the Clear ✕ control stays inside a narrow screen; their accessible names explain each function. The FROM and TO language boxes have stronger outlines.

Conversation: choose A and B languages and optionally Guest C; the three coloured A/B/C microphone controls appear above a shorter, scrollable conversation transcript on narrow screens, so all three stay accessible. Each completed message retains copy, replay and delete actions. Expand the draft section to type, dictate, polish or send a message. Speaker-language guidance is available in an expandable help section.

Speech input and three-speaker conversation

Tap the microphone for Speaker A, Speaker B or Guest C and grant microphone permission. The microphone is transcribed by Android’s installed speech-recognition service, not by Gemini, Groq or the AI model you choose for translation. The translation engine receives text after recognition; changing the AI model will not correct words Android already misheard.

If words are garbled, choose the actual speaker language (for example English, Vietnamese or Thai) instead of Auto. Speak directly toward the microphone, reduce music/TV/background conversation, and check that Android Speech Services and language packs are updated. Watch the live transcription before trusting the translation. Short, mixed-language or heavily accented phrases can be misunderstood by the installed recognizer.

Since v29: speech capture was adjusted to give Android more time to return final recognizer output and to support draft dictation at the cursor. Transcription appears while you speak when the installed recognizer supplies interim results. Actual timing and recognition accuracy remain dependent on Android speech services.

If speech recognition remains unreliable, type the original message instead; this bypasses microphone transcription entirely. Text translation and conversation mode remain distinct options in the app. Do not share private conversations or API keys in a public support issue.

Local data, backups and deletion

Open Privacy and data inside LinguaFast. You can adjust how long history is retained, make a manual JSON copy of records, restore a saved copy, or choose Clear local data to remove local history and saved API keys.

Uninstalling the Android app or clearing its storage can permanently remove unsaved data. Existing signed in-place upgrades are intended to keep data, but always save a copy of important translations beforehand. A history backup does not contain API keys and it is not encrypted once you export it.

LinguaFast does not currently provide a LinguaFast account-registration system or central user account to delete. If you used a third-party AI, translation or Android speech provider, deletion of LinguaFast's local records does not necessarily delete data they processed. Contact the relevant provider for their data-rights process. See the full retention and deletion policy.

Updates and release verification

Official signed builds are available in the latest-release feed. The most recently independently confirmed published release during this site update is v1.42.0 (build 42); use the live feed for newer releases. Do not mistake an unreleased private source branch for an installable APK. In the Android app, open About → Check now → Update now. The download and checksum verification are separate from Android's mandatory installation approval.

Updater changes from v34, with v35/v36 device confirmation: on Android 10 and later, the app uses a direct HTTPS download instead of relying on an Android Download Manager job that could remain stuck at Waiting with no bytes received. Progress displays bytes received and a percentage when the server provides a total. Partial downloads remain hidden until checked against the release SHA-256 twice. Older Android versions retain Download Manager. In-app updates to v35 and v36 have now been confirmed working on the owner’s Samsung, including Android installation approval. Individual phone security settings and downloads can still fail; use the app’s status messages to troubleshoot.

If an older updater is stuck: cancel it. If you have already built and verified the matching signed APK locally, open Samsung My Files → Internal storage → Download → LinguaFast, select the correctly versioned APK and choose Update, not Uninstall. Otherwise use the official release page and verify its SHA-256. Keep the package/signature unchanged and do not clear app storage. If Samsung or Play Protect flags the APK as harmful, stop rather than bypassing the protection.

Safety: if Google Play Protect or Samsung Auto Blocker describes an APK as harmful, stop. Do not override device protection to install it. A release signature and a matching checksum establish file identity, not that Google has classified the file as safe. Our earlier Play Protect warning remains under review.

Google Play Store status

The current public LinguaFast distribution is a signed APK through GitHub. We are preparing a separate Android App Bundle (AAB) release targeting Android API level 36 or higher, together with Play Console declarations, genuine device screenshots and a verified privacy/support contact.

LinguaFast is not yet advertised as Play Store approved. Approval depends on Google's review and, for some new personal developer accounts, closed testing requirements. A website and privacy notice are only parts of the submission process.

Report a problem

Use Report a LinguaFast issue on GitHub for non-sensitive reports, or consult the security notice before reporting a sensitive security concern. A private support contact will be published before Google Play submission.
